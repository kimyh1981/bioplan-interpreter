# 바이오플랜 동시통역 — 받기 · 설치 · 사용 안내

> **(주)바이오플랜 임직원 전용**입니다. 앱을 쓰려면 **회사 코드**가 필요합니다(전사 AX 총괄·글로벌사업팀에게 받기). 회사 코드는 외부에 공유하지 마세요.

| 무엇에 쓰나 | 받기 |
|---|---|
| **노트북(Windows)** — 온라인 통화(Zoom·Teams·카톡) + 대면 회의 | [BioplanInterpreter_PC_Setup.exe 받기](https://github.com/kimyh1981/bioplan-interpreter/releases/latest/download/BioplanInterpreter_PC_Setup.exe) (약 106MB) |
| **폰(안드로이드)** — 대면 회의(폰을 테이블에 두고) | [BioplanInterpreter_Phone.apk 받기](https://github.com/kimyh1981/bioplan-interpreter/releases/latest/download/BioplanInterpreter_Phone.apk) (약 26MB) |

> **"504 Gateway Time-out"이 뜨면** 깃허브 쪽 일시 장애입니다(우리 파일 문제 아님). 10~30분 뒤 다시 누르세요. 급하면 AX 총괄에게 파일을 카톡으로 받아도 됩니다(같은 파일, 이후 업데이트도 정상).
> 한 번 설치하면 다음부터는 **앱 안에서 자동 업데이트**됩니다(이 페이지에 다시 올 필요 없음).

## 1. 노트북(Windows) 설치 — 10~20분

**준비**: Windows 10/11 · 인터넷 · 빈 공간 약 5GB · **헤드셋(마이크 포함)** · 회사 코드
(인텔 Core Ultra 노트북이면 가장 빠르고 정확합니다. 아니어도 동작합니다.)
**상담 직전에 설치하지 마세요** — 설치 중 약 1.5GB를 내려받습니다.

1. 위 **노트북 받기**를 누릅니다.
   - 크롬이 **"확인되지 않음"** 또는 "일반적으로 다운로드되지 않는 파일"이라고 하면: `Ctrl+J`(다운로드 목록) → 해당 파일의 **유지**(또는 "안전하지 않은 파일 다운로드")를 누르세요. 사내 제작 파일이라 서명이 없어 뜨는 경고입니다.
2. 받은 `BioplanInterpreter_PC_Setup.exe`를 더블클릭합니다.
   - 파란 **"Windows의 PC 보호"** 창 → **추가 정보** → **실행**
3. 검은 창이 설치 폴더를 물으면 그냥 **Enter**(기본 `D:\BioplanInterpreter`). 창을 닫지 말고 기다립니다.
4. 끝에 나오는 판정 문구를 확인합니다.
   - `내장 GPU 사용 — 실시간 통역 정상` ← 가장 좋음
   - `GPU 없음 → CPU 경량 모델로 동작` ← 동작은 하지만 정확도가 낮음
5. 바탕화면의 **"바이오플랜 동시통역"** 아이콘으로 실행 → 첫 화면에 **회사 코드** 입력 → 저장(한 번만).

### 노트북 쓰는 법
1. 상단 **회의** 선택
   - **온라인**: Zoom/Teams/카톡 통화. 내 마이크 = 우리, PC 소리 = 상대.
   - **대면**: 노트북 마이크 하나로 모두. **대화 모드**를 켜면 오른쪽 칸이 뒤집혀 맞은편 상대가 그대로 읽습니다(노트북을 테이블에 눕혀 두고).
2. **상대 언어**(영어·베트남어·중국어·일본어)
   - 상대가 영어에 서툰 베트남·중국·일본 사람이면 **그 나라 말**을 고르세요(더 정확).
   - 그 외 나라면 **쉬운 표현** 체크.
   - **내 말**(온라인): 한국어 / 상대 언어로 직접 / 섞어서 — 실제로 말할 언어에 맞추세요.
3. **통역 시작** → 왼쪽 = 상대 말 → 한국어, 오른쪽 = 내 말 → 상대 언어. 말하는 중에 흐린 글씨로 먼저 뜨고, 문장이 끝나면 진하게 바뀝니다.
4. 상단 버튼
   - **리셋**: 화면을 비우고 새 대화(지난 대화는 저장됨)
   - **기록**: 지난 통역 목록 → 하나 열기 → **복사**(메일·메모에 붙이기)
   - **설정**: 회사 코드 변경 · 오늘 사용량 · 기록 폴더(원음·대화록 파일)

## 2. 폰(안드로이드) 설치 — 1~2분

1. 위 **폰 받기**를 폰에서 누르거나, PC에서 받은 파일을 카톡 '나와의 채팅'으로 보냅니다.
2. 파일을 누르면 "출처를 알 수 없는 앱" 안내 → **설정** → 크롬(또는 카카오톡·내 파일) **허용** → 뒤로 → **설치**
   - "Play 프로텍트" 경고 → **무시하고 설치**(사내 제작 앱이라 스토어 서명이 없음)
   - 설치가 막히면 설정 → 보안 → **자동 차단(Auto Blocker)** 을 잠시 끄고 설치 후 다시 켜세요.
3. 첫 실행: **설정** → 회사 코드 입력 → **통역 시작** → 마이크 허용 → **모델 내려받기(약 240MB, 와이파이)** — 한 번만. 베트남어 상대는 약 100MB를 더 받습니다.

### 폰 쓰는 법
- **위 칸(뒤집힘) = 상대가 읽는 칸**: 내가 한국어로 말하면 상대 언어로.
- **아래 칸 = 내가 읽는 칸**: 상대가 말하면 한국어로. 말하는 중에도 번역이 바로 뜹니다.
- **상대**: 영어·베트남어·중국어·일본어
- 상단 버튼
  - **리셋**: 새 대화(지난 대화는 저장됨)
  - **기록**: 지난 통역 목록 → 열기 → **복사**
  - **설정**: 회사 코드 · **대화 모드**(위 칸 뒤집기) · **소리로 읽기**(위 칸 번역을 폰이 상대 언어로 소리 내 읽음, 읽는 동안은 듣지 않음) · 오늘 사용량

## 꼭 지킬 것
- 통역 자막은 **대화 보조**입니다. **숫자·단가·납기·계약 조건은 말로 한 번 더 확인**하고(⚠ 표시가 뜨면 특히), 확정은 문서(메일·계약서)로 합니다.
- 음성은 기기 밖으로 나가지 않습니다. 받아쓴 **글자**만 번역을 위해 전송됩니다.
- 기기마다 **하루 사용 한도**가 있습니다. 넘으면 번역이 멈추고 다음 날 자동으로 풀립니다.

## 문제가 생기면
| 증상 | 해결 |
|---|---|
| 다운로드가 504 | 깃허브 일시 장애 — 잠시 뒤 다시, 급하면 AX 총괄에게 파일 받기 |
| 크롬 "확인되지 않음" | `Ctrl+J` → **유지** |
| 내 말(오른쪽/위)이 안 나옴 | 마이크 음소거·권한(설정 → 개인정보 → 마이크) 확인 |
| "PC 소리를 찾지 못해…" | 통화 앱 스피커를 Windows 기본 장치로 |
| "회사 코드가 맞지 않습니다" | 코드 다시 확인(띄어쓰기·하이픈 무시됨) |
| "오늘 사용 한도" | 다음 날 자동으로 풀림. 급하면 AX 총괄에게 |
| 업데이트 실패 | 인터넷 확인 후 다시 누르기(설정·기록은 그대로) |

문의: 전사 AX 총괄(글로벌사업팀) — 화면 캡처와 앱 창 제목(빌드 날짜)을 함께 보내 주세요.
