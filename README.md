# 바이오플랜 동시통역 — 다운로드

> **(주)바이오플랜 임직원 전용**입니다. 앱을 쓰려면 **회사 코드**가 필요합니다(전사 AX 총괄·글로벌사업팀에게 받기). 회사 코드는 외부에 공유하지 마세요.

## 받기
- **노트북(Windows)**: [BioplanInterpreter_PC_Setup.exe](https://github.com/kimyh1981/bioplan-interpreter/releases/latest/download/BioplanInterpreter_PC_Setup.exe) (약 106MB) — 온라인 통화(Zoom·Teams·카톡) + 대면 회의
- **폰(안드로이드)**: [BioplanInterpreter_Phone.apk](https://github.com/kimyh1981/bioplan-interpreter/releases/latest/download/BioplanInterpreter_Phone.apk) (약 28MB) — 대면 회의(대화 모드)
- 설치 안내: [노트북](https://github.com/kimyh1981/bioplan-interpreter/releases/latest/download/PC_install_guide_ko.md) · [폰](https://github.com/kimyh1981/bioplan-interpreter/releases/latest/download/Phone_install_guide_ko.md) · [전체 버전 목록](https://github.com/kimyh1981/bioplan-interpreter/releases)

## 처음 한 번
1. 노트북: 설치 파일 더블클릭 → Enter → 10~20분(인터넷 필요). 폰: APK 설치 → 첫 실행 때 와이파이로 모델 약 240MB.
2. 첫 화면에 **회사 코드** 입력 → 끝. (띄어쓰기·하이픈·대소문자는 상관없음)

## 꼭 지킬 것
- 통역 자막은 **대화 보조**입니다. 숫자·단가·납기·계약 조건은 말로 한 번 더 확인하고, 확정은 문서(메일·계약서)로 합니다.
- 음성은 기기 밖으로 나가지 않습니다. 받아쓴 **글자**만 번역을 위해 전송됩니다.
- 문제가 생기면 화면 캡처와 앱 창 제목(빌드 날짜)을 AX 총괄에게 보내 주세요.
