## 처음 한 번
1. 회사 **Claude API 키**를 전사 AX 총괄(글로벌사업팀)에게 받습니다. 키는 각자 기기에만 저장됩니다.
2. 노트북: 설치 파일 더블클릭 → Enter → 10~20분(인터넷 필요). 폰: APK 설치 → 첫 실행 때 와이파이로 모델 약 240MB.

## 꼭 지킬 것
- 통역 자막은 **대화 보조**입니다. 숫자·단가·납기·계약 조건은 말로 한 번 더 확인하고, 확정은 문서(메일·계약서)로 합니다.
- 음성은 기기 밖으로 나가지 않습니다. 받아쓴 **글자**만 번역을 위해 Claude API로 전송됩니다.
- 문제가 생기면 앱 창 제목(노트북)·버전(폰)과 화면 캡처를 AX 총괄에게 보내 주세요.
