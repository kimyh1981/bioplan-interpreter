바이오플랜 동시통역

임직원 전용

상대가 말하면 한국어로, 내가 말하면 상대 언어로 바로 보여 드립니다. 영어·베트남어·중국어·일본어.

회사 코드가 있어야 쓸 수 있습니다. 전사 AX 총괄(글로벌사업팀)에게 받고, 외부에는 공유하지 마세요.

⬇ 노트북용 받기 (Windows)

온라인 통화(Zoom·Teams·카톡) + 대면 회의 · 약 106MB(압축 파일)

⬇ 폰용 받기 (안드로이드)

대면 회의 · 폰을 테이블에 두고 · 약 26MB · 아이폰은 아직 지원하지 않습니다

노트북 설치 10~20분 · 상담 직전엔 피하세요

  1. 위의 '노트북용 받기'를 누릅니다.
    BioplanInterpreter_PC_Setup.zip(압축 파일)이 받아집니다.
  2. 받은 zip을 우클릭 › '모두 압축 풀기' › 압축 풀기.
    zip 안에서 바로 실행하지 말고 꼭 풀어 주세요.
  3. 풀린 BioplanInterpreter_PC_Setup.exe를 더블클릭합니다.
    파란 'Windows의 PC 보호' 창이 뜨면 추가 정보 › 실행. 사내 제작 프로그램이라 서명이 없어 나오는 안내입니다. 검은 창에서 Enter를 누르고 기다립니다(인터넷으로 약 1.5GB, 10~20분). 창을 닫지 마세요.
  4. 바탕화면 '바이오플랜 동시통역'을 열고 회사 코드를 넣습니다.
    한 번만 넣으면 됩니다. 끝입니다.
브라우저가 '확인되지 않음'·'일반적으로 다운로드되지 않습니다'라고 하면
  1. 다운로드 목록(Ctrl+J)에서 그 파일의 ⋯ › 유지(크롬은 '유지' 또는 '안전하지 않은 파일 다운로드') → 자세히 표시 › 그래도 계속.
  2. 파일은 이미 끝까지 받아진 상태입니다. 유지만 누르면 됩니다.
노트북 쓰는 법
  1. 회의: 온라인(통화 앱 소리 = 상대) 또는 대면(노트북 마이크 하나로 모두). 대면에서 대화 모드를 켜면 맞은편 상대가 읽도록 오른쪽 칸이 뒤집힙니다.
  2. 상대 언어를 고르고 통역 시작. 왼쪽 = 상대 말 → 한국어, 오른쪽 = 내 말 → 상대 언어.
  3. 상단 리셋(새 대화) · 기록(지난 통역 보기·복사) · 설정(회사 코드·오늘 사용량).
  4. 헤드셋을 쓰세요. 스피커로 들으면 상대 말이 내 마이크로 다시 들어갑니다.
설치가 막히면
  1. '504'나 '사이트에 연결할 수 없음'이면 깃허브 쪽 일시 장애입니다. 10~30분 뒤 다시 누르세요.
  2. 설치 중 실패하면 인터넷을 확인하고 받은 파일을 다시 실행합니다(이어서 안전하게 설치됩니다).
  3. 이미 깔려 있으면 다음부터는 앱 위쪽의 업데이트 줄을 누르면 됩니다(설정·기록 그대로).

폰 설치 1~2분

  1. 위의 '폰용 받기'를 누릅니다.
    다 받으면 알림이나 내 파일 › 다운로드에서 BioplanInterpreter_Phone.apk를 엽니다.
  2. '설치'를 누릅니다.
    '출처를 알 수 없는 앱' 안내가 나오면 설정을 눌러 이 브라우저의 '이 출처 허용'을 켜고 돌아옵니다. 플레이스토어 앱이 아니어서 나오는 안내입니다.
  3. 앱을 열고 설정에서 회사 코드를 넣습니다.
    통역 시작 › 마이크 허용 › 음성인식 모델 받기(약 240MB, 와이파이에서 한 번만).
  4. 끝입니다.
    다음부터는 앱이 새 버전을 알려 주고, 누르면 업데이트됩니다.
폰 쓰는 법
  1. 폰을 테이블에 둡니다. 위 칸(뒤집힘)은 상대가 읽는 칸, 아래 칸은 내가 읽는 칸입니다.
  2. 말하는 중에도 번역이 바로 뜨고, 문장이 끝나면 정확한 번역으로 바뀝니다.
  3. 리셋(새 대화) · 기록(지난 통역 보기·복사) · 설정(회사 코드·대화 모드·소리로 읽기·오늘 사용량).
  4. 소리로 읽기를 켜면 위 칸 번역을 폰이 상대 언어로 소리 내 읽어 줍니다(읽는 동안은 듣지 않습니다).
설치가 막히면
  1. 허용 칸이 회색이거나 '자동 차단이 설치를 막았습니다'가 뜨면 설정 › 보안 및 개인정보 보호 › 자동 차단을 끕니다(갤럭시). 설치한 뒤 다시 켜도 됩니다.
  2. Play 프로텍트 경고가 뜨면 세부정보 더보기 › 무시하고 설치를 누릅니다.
  3. 카톡 안에서 링크가 안 열리면 오른쪽 위 메뉴 › 다른 브라우저로 열기(크롬·삼성 인터넷).
  4. '504'가 뜨면 깃허브 쪽 일시 장애입니다. 잠시 뒤 다시 누르세요.

이런 걸 해 줍니다

  • 👂
    상대 말을 한국어로
    영어가 서툰 상대도 — 베트남·중국·일본 사람은 그 나라 말로 고르면 더 정확합니다
  • 🗣️
    내 말을 상대 언어로
    대면에서는 화면을 뒤집어 맞은편 상대가 바로 읽습니다
  • 🔢
    숫자는 두 번 확인
    숫자·단가가 의심스러우면 ⚠ 표시. 상대 통역사의 숫자가 다르면 알려 줍니다
  • 🗂️
    기록이 남습니다
    통역이 끝나면 저장되고, 기록에서 열어 메일·메모로 복사합니다
  • 🔒
    음성은 기기 밖으로 안 나갑니다
    받아쓴 글자만 번역을 위해 전송됩니다

꼭 지켜 주세요

  1. 통역은 대화 보조입니다.
    숫자·단가·납기·계약 조건은 말로 한 번 더 확인하고, 확정은 문서(메일·계약서)로 합니다.
  2. 기기마다 하루 사용 한도가 있습니다.
    넘으면 번역이 멈추고 다음 날 자동으로 풀립니다.
